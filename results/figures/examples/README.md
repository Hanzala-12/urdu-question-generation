# Example runs (front end)

Ten questions generated by the model in the Streamlit front end — **five good,
five bad** (Section 4.6). Each PNG is the full app view: input, marked source,
generated question, and the attention heat-map.

## Good — `good/`

| File | Sentence (answer span) | Decoding | Generated question |
|---|---|---|---|
| `e1.png` | سورج نظام شمسی کا مرکز ہے۔ (**سورج**) | beam | **شمسی نظام کا مرکز کیا ہے؟** — "What is the centre of the solar system?" |
| `e2.png` | مہاتما گاندھی نے عدم تشدد کا فلسفہ پیش کیا۔ (**عدم تشدد**) | beam | **مہاتما گاندھی نے کیا فلسفہ پیش کیا؟** — "What philosophy did Gandhi present?" |
| `e3.png` | ماؤنٹ ایورسٹ … جو نیپال میں واقع ہے۔ (**نیپال**) | beam | **ماؤنٹ ایورسٹ کہاں واقع ہے؟** — "Where is Everest located?" (beam beats greedy here) |
| `e4.png` | چاند زمین کے گرد چکر لگاتا ہے۔ (**زمین**) | greedy | **چاند کس سمت کے ارد گرد گھومتا ہے؟** — fluent, on-topic; slightly off ("direction") |
| `e5.png` | دریائے سندھ تقریباً 3180 کلومیٹر طویل ہے۔ (**3180 کلومیٹر**) | greedy | **دریائے سندھ کتنی ہے؟** — right question word "how much", incomplete |

## Bad — `bad/`

| File | Sentence (answer span) | Decoding | Generated question | Failure type |
|---|---|---|---|---|
| `b1.png` | ٹیلی ویژن کی ایجاد جان لوگی بیئرڈ نے کی۔ (**جان لوگی بیئرڈ**) | greedy | ٹیلی ویژن کی **کی** ایجاد کی **ایجاد** نے **ایجاد** کی؟ | **repetition** |
| `b2.png` | قائد اعظم محمد علی جناح 1876 میں کراچی میں پیدا ہوئے۔ (**کراچی**) | greedy | **دد علیاح** کس پیدا ہوا تھا؟ | **mangled proper noun** (long name → gibberish) |
| `b3.png` | بازنطینی سلطنت گیارہویں صدی میں کمزور ہو گئی۔ (**گیارہویں صدی**) | beam | بازنطینی سلطنت کس صدی میں **ہوئی**؟ | **dropped content word** ("کمزور ہو گئی" → just "ہوئی") |
| `b4.png` | نارمن دسویں صدی میں فرانس آئے۔ (**دسویں صدی**) | beam | کس صدی میں **فرانس … فرانس … فرانس … فرانس … فرانس**؟ | **attention collapse / severe repetition** — every generated token attends to the one "فرانس" column |
| `b5.png` | وہ ڈنمارک، آئس لینڈ اور ناروے کے نارمن حملہ آوروں سے … (**نارمن حملہ آوروں**) | beam | **آئس لینڈ اور آئس لینڈ اور آئس لینڈ** کے درمیان تعلق رکھتے تھے؟ | **repetition + ignores the marked answer** (asks about Iceland) |

The full 60 validation outputs (source / reference / greedy / beam) are in
[`results/samples.tsv`](../../samples.tsv).
